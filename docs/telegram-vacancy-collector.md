# Сбор вакансий из Telegram

`@jhubkz_bot` получает новые сообщения о вакансиях только из явно
разрешённых каналов, принадлежащих JobHub. Это отдельный процесс long
polling в `backend/cmd/telegram-collector`; он не реализует поиск или
уведомления соискателей. Его остановка не останавливает HTTP API.

## Процесс и границы безопасности

Collector обращается напрямую к официальному Telegram Bot API через
стандартную библиотеку Go. При запуске проверяет
`getMe.username == jhubkz_bot`, запрашивает только `channel_post` и
`edited_channel_post`, преобразует ответ в упрощённую модель сообщения,
проверяет числовой ID канала, детерминированно разбирает текст и передаёт
нормализованную внешнюю вакансию в существующий сервис импорта.

Серверные настройки:

- `TELEGRAM_BOT_TOKEN` — обязательный токен; не передавайте в `VITE_*`.
- `TELEGRAM_ALLOWED_CHANNEL_IDS` — отрицательные числовые ID через запятую.
  Пустое значение выполняет только проверку `getMe` и завершает процесс.
- `TELEGRAM_DEV_DATABASE_URL` — явная локальная база `jobhub_telegram_poc_*`.
  Запись отклоняется вне `APP_ENV=development`.
- `TELEGRAM_OFFSET_FILE` — приватный постоянный файл позиции, по умолчанию
  `./storage/telegram-collector.offset`.

Публичное имя канала не даёт права импорта: важен только разрешённый
числовой ID. Collector не ищет каналы, не читает историю, не скачивает
медиа, не сканирует сайты и не запускает OCR/AI. При первом старте старый
backlog подтверждается без импорта; затем обрабатываются только новые
сообщения. Храните файл позиции на постоянном диске. Позиция атомарно
продвигается только после безопасного пропуска или успешной транзакции БД.
Повторная доставка безвредна благодаря `UNIQUE(source, external_id)`.

## Идентификаторы и ссылки

Для ID канала `-100123` и ID сообщения `42`:

- источник: `telegram:-100123`;
- внешний ID: `telegram:-100123:42`;
- исходный URL при наличии публичного username:
  `https://t.me/<username>/42`.

Канал без публичного имени пропускается с `missing_source_url`; ссылка не
выдумывается. Отклик на такую вакансию остаётся внешним переходом к
исходному сообщению. Поддельный аккаунт работодателя или компании не
создаётся.

## Разбор сообщения

Полный исходный текст либо подпись медиа становится описанием. Parser берёт
первое явно подписанное значение:

- должность: `Вакансия`, `Должность`, `Лауазым`, `Бос орын`;
- компания: `Компания`, `Работодатель`, `Жұмыс беруші`;
- место: `Город`, `Место`, `Локация`, `Қала`, `Орналасқан жері`;
- зарплата: `Зарплата`, `Оклад`, `Жалақы`, `Еңбекақы`.

Значения не переводятся и не выводятся предположением. Отсутствующие
компания, место, зарплата, тип занятости, формат, валюта и опыт остаются
`NULL`. Для принятия сообщения нужны непустой текст, осмысленная
подписанная должность, стабильный ID и публичный `t.me` URL. Причины
пропуска: `source_not_allowed`, `empty_text`, `missing_source_url`,
`missing_title`, `validation_failed`. Ссылки в описании остаются частью
исходного текста; внешняя ссылка отклика всегда ведёт к исходному посту.

Telegram рассматривается как поток событий. Отсутствие сообщения в
следующей порции данных не закрывает вакансию. Редактирование поста
обновляет запись с тем же source/external ID.

## Подключение тестового канала JobHub

1. Создайте или откройте собственный **публичный** тестовый канал JobHub.
2. Добавьте `@jhubkz_bot` администратором без прав публикации,
   редактирования, удаления, приглашения и управления подписчиками: для
   collector нужен только доступ к сообщениям канала.
3. Определите числовой ID официальным Bot API. Из корня репозитория
   выполните `set -a; . ./.env; set +a`, затем в `backend/` —
   `go run ./cmd/telegram-collector --resolve-channel <public_username>`.
   Возьмите `chat_id` из безопасного лога. Не отправляйте токен сторонним
   lookup-ботам или сайтам. Поиск username помогает настройке, но не
   разрешает импорт.
4. Укажите отрицательный ID в корневом `.env`:
   `TELEGRAM_ALLOWED_CHANNEL_IDS=-100...`. Токен бота не меняйте.
5. Создайте отдельную локальную базу с префиксом `jobhub_telegram_poc_`,
   примените локальные миграции и задайте её loopback URL в
   `TELEGRAM_DEV_DATABASE_URL`.
6. Запустите процесс:

   ```sh
   set -a; . ./.env; set +a
   cd backend
   go run ./cmd/telegram-collector
   ```

7. После запуска опубликуйте тестовое сообщение:

   ```text
   Вакансия: Go-разработчик
   Компания: JobHub Test
   Город: Алматы
   Зарплата: 500 000 ₸

   Тестовая внешняя вакансия.
   ```

8. Проверьте лог принятия (только ID чата/сообщения и счётчики) и запись
   через существующий публичный API вакансий. Остановите процесс `Ctrl+C`.

Collector регистрирует только неподтверждённые источники разработки.
Запись в staging/Production заблокирована. Права на повторную публикацию,
хранение и коммерческое использование, атрибуция, модерация и политика
жизненного цикла требуют отдельного согласования перед Production.
