# Хранение резюме

Резюме соискателей — приватные файлы. Их нельзя отдавать как статические
ресурсы frontend.

## Локальная разработка

- Docker использует закрытый volume `resume_data`.
- При ручном запуске backend путь задаёт `RESUME_STORAGE_DIR`.
- Тестовые фикстуры не должны содержать настоящие резюме.

## Правила доступа

- Соискатель читает и заменяет своё активное резюме.
- Работодатель читает снимки резюме только в откликах на вакансии своей компании.
- Загрузка нового резюме не меняет снимки существующих откликов.

## Продакшен

В Production используется закрытый bucket Supabase Storage `resumes` с
серверным доступом. Не раскрывайте путь к файлу через публичный URL,
frontend или логи.
