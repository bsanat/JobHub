# Правила видимости вакансий

У собственных вакансий JobHub и импортированных внешних вакансий разные
правила публичной видимости.

## Собственные вакансии

Собственная вакансия видна, только когда это позволяют статус компании и
состояние вакансии. Черновики, приостановленные, закрытые, удалённые и
просроченные вакансии скрываются из поиска.

## Импортированные вакансии

Для импортированной вакансии нужны:

- включённый источник;
- подтверждённые права для Production;
- публичный URL источника;
- актуальность данных;
- внешний способ отклика.

## Общее правило

Список, счётчик и подробная страница должны применять одинаковый критерий
видимости. Вакансия, скрытая из списка, не должна открываться публично по ID.
